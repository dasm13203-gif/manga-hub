# مانجا هب: متجر + لوحة تحكم

موقع ثابت (HTML/CSS/JS) بيشتغل على GitHub Pages، وقاعدة البيانات والدخول والصور على Supabase.

## الملفات

| الملف | وظيفته |
|---|---|
| `index.html` + `store.js` | المتجر: الكتالوج والسلة والطلب الخاص |
| `admin.html` + `admin.js` | لوحة التحكم (دخول بإيميل وباسورد) |
| `config.js` | رابط Supabase والـ anon key (اللي هتعدله) |
| `common.js` | أدوات مشتركة |
| `style.css` | التصميم |
| `supabase.sql` | الجداول والأمان ودوال الطلب |
| `logo.jpg` | الشعار |

## الإعداد (حوالي 10 دقايق)

### 1) Supabase
1. اعمل مشروع جديد على supabase.com.
2. روح **SQL Editor**، الصق محتوى `supabase.sql` كله واضغط **Run**.
3. روح **Authentication > Users > Add user**، اعمل حساب ببريدك وكلمة مرور قوية.
4. ارجع للـ SQL Editor وشغّل السطر ده (غيّر البريد):
   ```sql
   insert into public.admins (user_id) select id from auth.users where email = 'YOUR-EMAIL@example.com';
   ```
5. روح **Project Settings > API** وانسخ **Project URL** و **anon public key**.
6. افتح `config.js` وحطهم مكان `YOUR-PROJECT` و `YOUR-ANON-KEY`.

### 2) GitHub Pages
1. ارفع كل الملفات في ريبو جديد (في الجذر مش جوه فولدر).
2. **Settings > Pages > Deploy from a branch > main / root**.
3. الموقع هيفتح على `https://USERNAME.github.io/REPO/` ولوحة التحكم على `/admin.html`.

### 3) أول استخدام
1. افتح `/admin.html` وسجّل دخول.
2. من **الإعدادات** راجع رقم واتساب وسعر الشحن (القيم الافتراضية مبدئية).
3. من **المنتجات** اضغط **إضافة كتاب** وارفع الأغلفة.

## إزاي الطلب بيشتغل
- الزبون بيملا السلة والبيانات ويضغط تأكيد، والطلب بيتسجل في Supabase فورًا ويظهر في لوحة التحكم تحت **الطلبات**.
- بعدها بيظهر له زر يفتح واتساب برسالة جاهزة فيها رقم الطلب لتأكيد الشحن والمواعيد.
- الأسعار والشحن والمخزون بتتحسب على السيرفر (دالة `place_order`)، فمفيش حد يقدر يغيّر سعر من المتصفح.
- إلغاء الطلب من اللوحة بيرجّع الكميات للمخزون تلقائي.

## ملاحظات أمان
- الـ anon key عادي يبقى ظاهر في الموقع. الحماية من سياسات RLS في `supabase.sql`: الزبون يقدر يقرا الكتب النشطة والإعدادات ويبعت طلب بس. الطلبات نفسها مقروءة للمدير فقط.
- لو جالك طلبات وهمية كتير، فعّل CAPTCHA من Supabase (Authentication > Attack Protection) أو حط Cloudflare قدام الدومين.
- أغلفة الكتب من رفعك أنت. تأكد إن عندك حق استخدام الصور اللي بترفعها.

## دومين خاص (mangahub.eg)
في GitHub Pages اكتب الدومين في **Custom domain**، وفي إعدادات الـ DNS أضف سجلات GitHub Pages الموضحة في وثائقهم، وفعّل **Enforce HTTPS**.

## إشعارات تلجرام
1. في تلجرام افتح **@BotFather** وابعت `/newbot`، اختار اسم ويوزر للبوت، وانسخ **التوكن**.
2. افتح البوت بتاعك وابعتله `/start`.
3. افتح في المتصفح `https://api.telegram.org/bot<التوكن>/getUpdates` وهتلاقي `"chat":{"id":123456789,...}`: الرقم ده هو الـ **chat id**.
4. شغّل `telegram.sql` في SQL Editor.
5. شغّل السطر الأخير (insert) بالتوكن والـ chat id بتوعك.
6. جرّب طلب تجريبي من المتجر، المفروض تيجيلك رسالة في ثواني.

التوكن بيتخزن في جدول سري في Supabase ومش بيظهر في الموقع ولا في الكود. ماترفعوش على GitHub.
